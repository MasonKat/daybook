# DAYBOOK 운영 가이드

선생님용 한 장짜리 안내입니다. 버튼 이름은 화면에 보이는 그대로 적었습니다.
노트북의 DAYBOOK 폴더에서 `.venv\Scripts\python.exe -m console board <반 이름>`을 켜면 보드(http://127.0.0.1:8787)와 선생님 탭(오른쪽 위 "선생님")이 열립니다.
인쇄본은 `.venv\Scripts\python.exe -m console guide`로 만듭니다.
아래의 명령도 모두 같은 방식입니다: `daybook …` 대신 `.venv\Scripts\python.exe -m console …`. 종이에는 학생 링크를 절대 적지 않습니다.

## 수업 전 (10분)

1. 노트북에서 보드를 켭니다: `.venv\Scripts\python.exe -m console board 고1A`.
2. 선생님 탭 → **점검**을 누릅니다. ✗가 없으면 시작해도 됩니다. ⚠는 읽고 필요하면 고칩니다.
   - "session not started"는 수업 전이면 정상입니다. 보드를 켜면 바로 시작됩니다.
3. 보드 위쪽의 **오늘의 코드**(숫자 4개)를 확인합니다. 칠판에 적거나 프로젝터에 띄웁니다.
4. 프로젝터에는 **보드 화면만** 띄웁니다. **선생님 보기**는 꺼 둡니다.
5. 주간 테스트가 있는 날이면 선생님 탭 → **주간 테스트**에서 회차가 "진행 중"인지 봅니다.

## 수업 중

- **출석**: 학생은 오늘 탭의 ① 출석을 누르고 코드를 칩니다. 시작 30분 전부터 60분 뒤까지 됩니다.
  - 휴대폰이 없거나 안 되는 학생은 보드에서 그 학생 줄의 **출석 처리**를 누릅니다.
- **태도 점수**: 보드에서 학생 줄의 **1 · 2 · 3**을 누릅니다. 점수는 올라가기만 합니다.
- **장면 올리기**: 보드 아래 **장면 올리기**에서 사진을 고르고 한 줄을 씁니다.
  "학생 얼굴·이름·문제집 원문 전체가 보이지 않나요?"를 확인하고 체크한 뒤 올립니다. 한 수업에 3장까지입니다.
- **AMP Live**(선택): 보드 위 **AMP Live** → 문제 세트 고르기 → **방 열기** → 방 번호를 보여 줍니다.
  **다음 문제** → **정답 공개** → 끝나면 **방 닫기**. 반의 80% 이상이 맞히면 반 점수 +5입니다.
- 학생 이름과 사유가 보이는 **선생님 보기**는 프로젝터에 띄우지 않습니다.

## 수업 끝

- 학생은 오늘 탭에서 **과제 끝 · 찍고 가자** → 사진 → **올리기**를 합니다.
  오늘 한 줄, 칩, 오늘 푼 문제 수는 선택입니다.
- 사진을 못 찍는 학생은 보드의 **대신 제출**을 누릅니다. 종이로 낸 과제도 같습니다.
- 와이파이가 없으면 학생 휴대폰에 "보낼 준비 완료"가 뜹니다. 연결되면 저절로 한 번만 보내집니다.
- 수업이 끝나면 보드 창을 닫아도 됩니다.
- **음성 메모**(선택): 클로바노트로 "칭찬 가람 2점 …", "개념 …", "장면 …"을 녹음하고 텍스트로 내보냅니다.
  선생님 탭 → **음성 메모 가져오기**에 붙여 넣고 **미리보기** → "누구?" 줄은 학생을 고르고 → **저장**.

## 토요일 (30~40분)

선생님 탭에서 위에서 아래로 진행합니다.

1. **점검**을 누릅니다.
2. 주간 테스트 회차가 끝났으면 **주간 테스트** → 그 회차의 **✓**로 제출 현황을 봅니다. (현황은 발행 뒤에 바뀝니다.)
3. 같은 줄의 **내보내기**를 누릅니다. `reports/<회차>.csv`가 생깁니다. (Notion 연동은 로컬 에이전트가 이 파일로 합니다.)
4. **가져오기**: 스크리너 라운드 파일, 분석 결과(insights.json)를 넣습니다.
5. **이번 주 한 줄**: 초안을 고치고 **저장**합니다.
   **학생 리뷰**: "확인 대기"의 리뷰를 읽고 **승인** 또는 **숨김**을 누릅니다. 승인한 리뷰만 같은 반 친구들에게 보입니다.
6. **연락 필요**와 **이번 주 할 일**: 전화할 분을 확인합니다. 통화 뒤 **통화함**을 누르고 한 줄을 적습니다.
7. **발행**을 누릅니다. 개인정보 검사를 통과해야 페이지가 만들어집니다. 끝나면 백업도 저절로 됩니다.
8. **배포**를 누릅니다. 학생·학부모 페이지가 바뀝니다.
9. **주간 메시지**: 필요하면 복사해서 보냅니다.
10. USB 백업이면 마지막에 **백업**을 한 번 더 누르고 USB를 뺍니다.

## 학생 추가 · 퇴원 · 링크 재발급

선생님 탭 → **명단 · 반 관리**.

- **학생 추가**: 이름(전체), 표시 이름, 반, 학생 ID, 학부모 전화를 넣고 **학생 추가**를 누릅니다.
  새 링크 두 개와 안내 문구 버튼이 나옵니다.
  - **학부모 안내 복사** → 학부모님께 카톡 1:1로 보냅니다.
  - **학생 안내 복사** → 학생에게 카톡 1:1로 보냅니다.
- **반 이동**: 학생 줄의 반을 바꿉니다. 기록은 그대로 남습니다.
- **퇴원**: 학생 줄의 **퇴원**을 누릅니다. 다음 배포부터 페이지가 사라집니다. **되돌리기**로 취소할 수 있습니다.
- **링크 재발급**: 링크를 잃어버렸거나 다른 사람에게 갔을 때 누릅니다. 이전 링크는 바로 막힙니다.
  새 링크를 안내 문구로 다시 보냅니다.
- 명단 CSV가 있으면 **가져오기 미리보기**로 먼저 확인하고 **이대로 가져오기**를 누릅니다.

## 학부모 안내문과 동의서

1. 반마다 안내문을 인쇄합니다: `.venv\Scripts\python.exe -m console cards parents 고1A`. 한 장에 한 가정입니다.
   - 안내문에는 기록하는 것(출석 시각, 과제 사진, 태도 점수, 주간 테스트, 영상 시청 여부, 선생님 한 줄), 보관 방법, 알림, 그만두는 방법이 있습니다.
   - 학생 이름, 링크, QR은 인쇄하지 않습니다. 학부모님이 아래 동의서에 학생 이름을 직접 씁니다.
2. 아래쪽 동의서를 잘라 받습니다.
3. 받은 동의서를 기록합니다: 선생님 탭 → **연락 현황**에서 학생 줄의 동의 칸을 **동의** 또는 **동의 안 함**으로 바꿉니다.
   (`.venv\Scripts\python.exe -m console roster edit <학생> --consent yes`)
4. **동의**가 아닌 학생은 학부모 페이지가 만들어지지 않고, 영상 시청 기록과 알림도 쓰지 않습니다. 학생의 출석과 과제는 그대로 됩니다.
5. **점검**의 "consent ⚠"는 아직 받지 못한 동의서입니다. 수업은 막지 않습니다.
6. 그만두고 싶다고 하시면 동의 칸을 **동의 안 함**으로 바꾸고 **링크 재발급**을 누릅니다. 기록 삭제를 원하시면 담당자에게 알립니다.

## 문제가 생기면

1. **점검에 "Worker /health ✗"**: 인터넷을 확인합니다. 그래도 안 되면 `cd worker && npx wrangler deploy`.
2. **점검에 "Worker version ⚠"**: Worker가 예전 버전입니다. `cd worker && npx wrangler deploy`.
3. **학생이 링크를 잃어버림**: 명단에서 **학생 안내 복사**로 다시 보냅니다. 남이 가져갔으면 **링크 재발급**.
4. **"코드가 달라요"**: 칠판의 코드를 다시 보여 줍니다. 5번 틀리면 그날은 **출석 처리**로 합니다.
5. **"지금은 출석 시간이 아니에요"**: 시작 30분 전~60분 뒤만 됩니다. 보드의 **출석 처리**를 씁니다.
6. **카메라가 없거나 안 열리는 휴대폰**: 보드의 **대신 제출**을 누르고, 종이 과제는 수업 끝에 걷습니다.
7. **교실 와이파이가 안 됨**: 학생 휴대폰에 "보낼 준비 완료"가 뜹니다. 연결되면 한 번만 보내집니다. 다시 찍지 않아도 됩니다.
8. **주간 테스트 카드가 안 보임**: 주간 테스트 회차의 반과 시간을 확인합니다. 회차를 저장한 뒤 학생은 페이지를 새로 엽니다.
   점검의 "student links on the Worker"가 ⚠이면 **발행**을 한 번 누릅니다.
9. **발행이 멈춤 ("lint failed")**: 표시 이름이나 한 줄에 전체 이름, 전화번호가 들어갔습니다. 그 글을 고치고 다시 **발행**.
10. **학부모 페이지가 안 바뀜**: 발행 뒤 **배포**를 눌렀는지 봅니다. 페이지는 토요일에 한 번 바뀌는 것이 정상입니다.

그래도 안 되면 노트북 화면을 사진으로 찍어 담당자에게 보냅니다. 학생 이름이 보이면 가리고 보냅니다.
