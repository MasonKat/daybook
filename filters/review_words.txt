# DAYBOOK 학생 리뷰 금지어 (F18.3). One word or phrase per line; # starts a comment.
# The filter ignores spaces, symbols and digits between letters, reads 초성 (ㅅㅂ), and reads Latin letters typed on
# a Korean keyboard (tlqkf = 시발), so one plain entry covers its variants. Extend it locally in
# filters/review_words.local.txt (gitignored); publish sends the merged list to the pages and the Worker.
# Words that must never be blocked (e.g. 시발점) go in a line starting with "!".
# Elongation is read through: a syllable that only repeats the previous vowel is dropped (시이발, 씨이이발, 조오온나).
# A plain group word (장애인, 흑인, 여자, 노인) is never listed alone: only its insulting forms and patterns are.
